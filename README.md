# Yodda Qol

Odamlarning rasmi, ismi va ma'lumotini saqlab boradigan shaxsiy katalog: hech kimni unutmaslik uchun.
Internetsiz ishlaydi va telefonga ilova sifatida o'rnatiladi (PWA).

**Ochish:** https://mjavohir06.github.io/Yodda_qol2/

**Texnologiyalar:** HTML, CSS, JavaScript, IndexedDB, Service Worker (PWA)

## Imkoniyatlar
- Kamera orqali rasmga olish yoki galereyadan tanlash
- Ism va qo'shimcha ma'lumot yozish, odamlar ro'yxati
- Ma'lumotlar faqat qurilmaning o'zida saqlanadi, zaxira nusxa olish va tiklash mumkin
